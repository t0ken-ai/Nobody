## 自动更新

- 启动后自动检查 GitHub 正式版本，后台每 6 小时检查一次。
- 菜单栏与偏好设置新增「检查更新」，提醒中显示版本号和更新摘要。
- 支持稍后提醒、跳过当前版本及关闭自动检查。
- 点击「更新并重启」后下载更新包，校验签名和版本，再安装并重启。
- 翻译或局域网传输仍在进行时暂缓安装，不打断当前任务。

## 发布与展示

- macOS Apple 芯片安装包、签名更新包和更新清单通过 GitHub Releases 发布。
- README 增加演示预览、下载入口，以及适配深浅背景的透明 Logo。

## 安装提示

这是首个内置自动更新的版本。0.1.0 用户需要手动安装一次，后续即可在应用内更新。

当前自动安装支持 macOS Apple 芯片；Windows 更新接口已预留，安装包与实机更新仍待验证。
macOS 包使用 ad-hoc 签名，尚未进行 Developer ID 签名或 Apple 公证。
