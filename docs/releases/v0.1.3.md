## 桌面体验

- 新增「关于 Nobody」：显示真实安装版本、GitHub 项目地址及作者邮箱 spridu@gmail.com，可从窗口底部或菜单打开。
- 新增 macOS / Windows「登录时启动」开关，默认关闭；开启后登录系统时后台运行，不弹出主窗口。
- 保存设置与检查更新按钮统一尺寸和对齐方式，开机启动选项即时生效，无需另点保存。

## macOS 安装盘图标

- 为挂载后的安装磁盘补齐 Nobody 图标。
- 新增 `.dmg.zip` 下载，使用 macOS 解压后可保留 DMG 文件的自定义图标；裸 `.dmg` 经网页下载时不保留 Finder 扩展元数据，仍可能显示通用图标。
- 保留原有 DMG、应用 ZIP 和签名自动更新包。

## 更新说明

现有翻译设置、LLM 配置和本地互传数据会保留。macOS 仍使用 ad-hoc 签名，更新后系统可能要求重新开启辅助功能权限；更新包验签不能替代 Apple Developer ID 签名。Windows 暂无 Authenticode 发布者证书，跨应用交互仍需实机反馈。
