## Windows 安装与更新

- 新增 Windows x64 `.exe` 安装包，默认安装到当前用户目录。
- Windows 安装器提供中英文界面；缺少 WebView2 时会下载所需运行时。
- Windows 接入签名自动更新，提醒显示版本摘要，确认后下载、验签、安装并重新启动。
- 发布检查覆盖 Windows 真实安装器的全新安装与更新模式覆盖；跨应用划词等桌面交互仍需实机反馈。

## 双平台发布

- macOS Apple 芯片与 Windows x64 安装包统一发布到同一个 Release。
- 两个平台都构建并校验成功后才发布合并的更新清单，避免覆盖或遗漏某个平台。
- 缺少平台文件、校验值不符或摘要不一致时中止发布。

## 安装提示

macOS 0.1.1 用户可以在应用内检查并升级；0.1.0 用户需手动安装。
Windows 用户首次下载安装 `.exe`，后续可在应用内更新。Windows 使用自定义 LLM，不提供 Apple 系统翻译。

更新包均有独立的更新签名。macOS 仍为 ad-hoc 签名、未经 Apple 公证；Windows 暂无 Authenticode 发布者证书。Windows ARM 原生包和跨应用交互实机验收暂未提供。
