# 使用指南

[返回 README](../README.md)

## 写入与阅读

写入快捷键将内容翻译成英文：优先使用选中文字；没有选区时，尝试读取当前可编辑输入框。回填前再次核对来源应用、控件、原文和选区；内容变化、超时或不可写时，只展示译文供复制，不覆盖正在编辑的内容。应用不会代按发送键。

阅读目标语言可以在「偏好设置」修改。自动划词在鼠标或触控板拖选、双击选词并松开后触发；纯键盘选词请使用手动阅读快捷键。macOS 演示使用三指拖移，需要在系统中自行开启；实际操作也支持鼠标及其他系统选词方式。

译文浮窗优先位于选区上方，空间不足时放在下方。拖动顶部可以移动本次结果；新选区重新跟随。坐标不可用时使用触发时的指针附近位置。当前宽度固定，高度按内容和屏幕空间调整，长文在内部滚动，暂不支持手动缩放。

点击关闭，或浮窗获得焦点后按 `Esc`，可收起结果。macOS 仅在 Nobody 仍为前台应用时将焦点交还给上一个外部应用；已切到其他应用时不抢回焦点。

## 自动划词白名单

默认只允许 ChatGPT Desktop 和 Claude Desktop。点击「添加本机应用」选择 `.app`（macOS）或 `.exe`（Windows），然后保存。macOS 选择器默认打开 Applications，Windows 默认打开 Program Files。

- 白名单仅限制自动划词，手动快捷键和翻译工作台不受此限制。
- Codex 与 ChatGPT Desktop 是不同应用；使用 Codex 时需要手动添加。
- macOS 默认项按 Bundle ID 识别；自选项同时核对规范化路径与 Bundle ID。Windows 自选项按规范化完整路径识别；默认项使用可执行文件名，尚未进行客户端实机身份验收。
- 不根据窗口标题或网页域名放行。移动自选应用后需重新添加；未安装的默认项会显示未安装。
- 保存空列表可禁用所有应用的自动划词；也可直接关闭自动划词开关。

自动模式忽略输入框、搜索框、保存／打开／重命名对话框、受保护字段，以及已识别的纯数字、路径、URL 和代码。恢复旧选区、切回窗口或程序默认全选，不应单独触发翻译。无法可靠判断控件用途时不自动弹窗，可以改用手动快捷键或工作台。

## 翻译引擎

### 系统翻译

macOS 15+ 使用 Apple Translation，语言支持与模型安装状态由系统判断。首次缺少模型时会进入系统下载流程，同一组语言的正反向翻译复用已安装模型；新增语言或系统移除模型后仍可能需要下载。

macOS 26+ 且使用相应 SDK 构建时，已安装模型走无下载权限的会话，不显示准备窗口。较旧系统或 SDK 保留系统要求的界面会话。短词或命令的语种判断不可靠且没有可用模型时，会提示使用完整句子或切换 LLM，避免因误识别下载其他语言。

### 自定义 LLM

1. 选择「自定义 LLM」，填写接口地址、模型 ID 和 API Key，或使用界面提供的预设。
2. 可编辑「角色与翻译规则」。默认语气为自然、简洁的美式开发者沟通，并要求保留技术关键词、代码、注释和命令。
3. 点击「测试连接」，使用当前表单内容翻译固定测试句。
4. 点击 **保存设置** 才会切换实际引擎。保存后重新翻译，旧结果不会自动更新。

接口需兼容 Chat Completions 并支持 SSE 流式响应。可以填写基础地址或完整 `/chat/completions` 地址；远程服务要求 HTTPS，本机回环地址可使用 HTTP，例如 `http://localhost:11434/v1`。模型名称和接口可自由修改，预设不代表所有账号都能使用对应模型。

API Key 留空会保留该接口已保存的密钥，勾选删除后保存才会移除。没有已保存密钥时，Z.ai / Kimi 的对应 Coding Plan 地址可读取应用进程继承的 `ZAI_KEY` / `KIMI_KEY`；应用不读取 shell 配置文件，从 Finder 启动通常需要在设置中填写密钥。

### 段落、代码与 Markdown

系统引擎按自然语言片段翻译，保留已有换行、围栏代码、行内代码和可识别的技术片段。macOS 阅读时会尝试恢复选区接口遗漏的段落分隔；结构不足或原文核对不一致时保留原始选文，不把视觉自动折行当作新段落。

LLM 接收完整上下文，可将没有 Markdown 标记但能够识别的代码整理成代码块。本地会校验已知代码和技术片段，空白、截断或校验失败时不回填。**这不是完整的代码解析器**：混合正文中的未标记代码、注释和命令仍可能无法准确识别，无法找回选区中已经丢失的内容。代码密集的内容优先复制原始 Markdown 到工作台。

浮窗和工作台支持被动 Markdown 排版，不执行 HTML、不加载远程图片或打开链接。复制与回填保留 Markdown 源文。

## 局域网互传

两端都需运行 Nobody 并允许本地网络访问。应用通过 mDNS 发现在线设备，使用 TLS 1.3 直连；当前网络范围为 IPv4 私有／链路本地地址。访客网络隔离、不同网段、组播限制、VPN 和防火墙可能影响发现或连接。

首次向设备发送时，两端会显示六位校验码。核对一致并分别确认信任后才传正文和文件；拒绝或两分钟内未完成确认，不传这些内容。后续验证已保存的设备身份后自动接收；名称或 IP 相同不会自动获得信任。「解除信任」同时取消该设备的当前任务。

- 支持文字、单个文件和多个文件；不支持文件夹、符号链接和不兼容 Windows 的文件名。
- 文字上限 1 MiB；每次最多 100 个文件，单文件 20 GiB，文件合计 40 GiB。这些是协议上限，不代表所有大小均已实机测试。
- 文件分块传输并校验完整性，同名文件自动另存，收到后不自动执行。传输中修改源文件会报错。
- 默认接收目录为 `~/.translateme/received/`，可通过「本机与接收设置」修改。发送的源文件不会另存到应用目录。
- 记录每页 5 条，保留最近 100 条、文字总量最多 8 MiB。清除记录不删除已接收文件；收到的文字提供全文和复制操作。
- 关闭主窗口后继续接收；从菜单栏／托盘退出才停止服务。也可在设置中关闭互传。系统通知受系统权限与通知策略影响。

## 常见问题

**快捷键有效，但划词没有浮窗？**

确认自动划词已开启、当前应用在白名单内，且修改后点击了保存。只读正文中拖选或双击后松开；输入框和系统对话框默认忽略。目标应用若没有暴露可用文本接口，改用工作台。

**权限开关已开启，应用仍提示未授权？**

本地开发包重建后，macOS 可能仍保存旧签名的授权。先退出 Nobody，在系统设置的辅助功能权限中移除旧 Nobody／TranslateMe 条目，再添加当前实际运行的 `.app` 并开启权限，随后重新启动。系统要求的身份验证需由本人完成，以应用显示「跨应用翻译已就绪」为准。

**测试连接成功，为什么还在用系统翻译？**

测试只验证表单草稿。选中自定义 LLM 并保存设置后，再发起一次翻译；结果中的引擎标记对应生成该结果时使用的配置。

**找不到另一台电脑？**

确认两端正在运行、互传已开启、允许本地网络访问，且网络允许设备直接通信。已安装但未运行的电脑不会出现；同一 Wi-Fi 名称也不保证没有设备隔离。
