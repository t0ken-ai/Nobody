# Nobody · macOS 安装说明

语言不同，价值不减。

Nobody 为开发者提供快捷键翻译、划词阅读和局域网文字／文件互传。

## 下载

优先从 [GitHub Releases](https://github.com/t0ken-ai/Nobody/releases/latest) 下载 `Nobody-<版本>-macOS-arm64.dmg` 或 `.zip`。正式发布页同时提供每版更新摘要、SHA-256 校验清单和应用内更新所用的签名包，无需登录即可下载安装包。

0.1.3 起还提供 `.dmg.zip`：使用 macOS 自带解压工具解压后，DMG 文件保留 Nobody 自定义图标。直接通过 HTTP 下载裸 `.dmg` 不保留 Finder 扩展元数据，仍可能显示系统通用图标；挂载后的磁盘图标和磁盘内应用图标不受影响。普通 `.zip` 内是应用，`.dmg.zip` 内是安装磁盘。

测试提交的构建产物仍位于 [Actions → Build installers](https://github.com/t0ken-ai/Nobody/actions/workflows/macos-installers.yml)，保留 30 天，下载需登录 GitHub。推送匹配应用版本的 `v*` 标签会在构建成功后发布正式 Release；普通 `main` 提交只生成测试产物。

## 安装

1. 使用 `Nobody-<版本>-macOS-arm64.dmg`，适用于 Apple 芯片 Mac；ZIP 包内提供相同应用。
2. 升级前从菜单栏退出旧版 Nobody / TranslateMe，避免两个实例争用快捷键和互传端口。
3. 打开 DMG，将 Nobody 拖到「应用程序」后启动。

运行应用不需要 Node.js、Rust、Xcode 或另行安装 SQLCipher。应用最低系统版本声明为 macOS 13.0，Apple 系统翻译需要 macOS 15+；较旧系统需配置 LLM。macOS 13/14 和 Intel Mac 尚未完成实机验证。

当前构建采用 ad-hoc 签名，尚未 Developer ID 签名或 Apple 公证。首次打开可能被 macOS 阻止，请在确认来源后自行按系统提示处理，不要关闭系统安全保护。

## 自动更新

0.1.1 是首个支持自动更新的版本。0.1.0 用户需要先手动安装一次；之后可从菜单栏或「偏好设置 → Nobody 更新」检查更新。

- 启动 30 秒后检查，此后每 6 小时检查一次；可以关闭自动检查。
- 提醒显示新版本、发布日期和该版本 Release 的更新摘要，可稍后提醒或跳过此版本；手动检查仍能找到跳过的版本。
- 点击「更新并重启」后下载并校验签名及版本，再安装。翻译或局域网任务未结束时暂缓安装，请完成任务后重试。
- 网络或签名检查失败时不安装；没有对应平台安装包时不会改用其他平台文件。
- 当前 Release 同时提供 macOS Apple 芯片和 Windows x64 更新包。更新签名与 Apple Developer ID／公证是不同机制，辅助功能授权的升级行为仍需按系统提示处理。

更新使用 GitHub 上的公开 Release，不需要用户提供 GitHub Token、LLM Key 或钥匙串授权。偏好、密钥和互传文件保留在原位置。

## 首次使用

- **跨应用翻译**：在系统设置 → 隐私与安全中为 Nobody 开启辅助功能权限。以应用显示「跨应用翻译已就绪」为准。
- **翻译工作台**：可直接粘贴文字翻译，不需要辅助功能权限。
- **系统引擎**：缺少语言模型时按系统提示下载；同一语言组合的正反向复用已安装模型。
- **自定义 LLM**：选择引擎，填写接口、模型及 API Key，然后点击「保存设置」。「测试连接」只测试表单，不会切换已保存的引擎。
- **自动划词**：默认白名单为 ChatGPT Desktop、Claude Desktop。Codex 等其他应用需手动添加并保存；输入框和文件对话框默认不触发。
- **局域网互传**：两端运行应用并允许本地网络及接收目录访问；首次核对双方校验码后分别确认信任，之后自动接收。默认接收目录为 `~/.translateme/received/`，可修改。

写入英文快捷键为 `⌘⇧E`，手动阅读为 `⌘⇧D`，均可修改。自动划词无需快捷键。关闭主窗口后应用继续驻留菜单栏，从菜单中退出才停止后台服务。

在「偏好设置 → 登录时启动」开启后，下次登录系统时在后台运行，不弹主窗口。默认关闭，切换立即生效；请先将应用移入「应用程序」，不要从 DMG 或临时转移目录启用。应用不会在升级时自行开启此选项。窗口底部及菜单中的「关于 Nobody」显示真实版本、项目主页和作者邮箱。

## 授权与数据

开发构建的签名变化可能使旧辅助功能授权失效。若开关已开启但应用仍提示未授权，先退出应用，移除旧 Nobody／TranslateMe 授权条目，再添加当前实际运行的应用并开启权限，随后重启。系统要求的 Touch ID／登录密码验证需由本人完成。

安装包不含开发者的 API Key、设备身份、信任记录、聊天或收件文件。新电脑需要自行配置密钥和配对。Nobody 不访问钥匙串；API Key 数据库与解密密钥同存于 `~/.translateme/llm/`，获得整个目录即可解密，请妥善保管。

更名保留 `app.translateme.desktop` 和 `~/.translateme/`，无需为名称变化手动移动数据。旧系统凭据库版本升级时需重新填写密钥并配对设备。

## 校验安装包

在安装包和 `.sha256` 清单所在目录运行（替换实际版本号）：

```sh
shasum -a 256 -c Nobody-<版本>-macOS-arm64.sha256
```

平台清单包含 DMG、ZIP、签名更新包及平台元数据；合并后的 latest.json 提供单独的校验清单；只下载其中部分文件时，其余项会提示文件不存在，可单独计算已下载文件的 SHA-256 与清单对应项比对。
