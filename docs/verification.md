# 兼容性与验证范围

[返回 README](../README.md) · [复测命令](development.md#检查)

本文记录截至 2026-09-28 的已知状态，不将历史构建的检查结果视为所有平台或后续版本的保证。临时样例、原始日志和旧安装包哈希不随仓库分发。

## 已验证的范围

主要实测环境为 Apple 芯片 Mac、macOS 27；双机互传使用两台实体 Mac。部分能力经过用户手工验证，自动检查与人工检查分别列出。

| 能力 | 验证证据 | 范围限制 |
| --- | --- | --- |
| macOS 启动与构建 | Release 应用实际启动，签名及 DMG / ZIP 完整性检查通过 | 当前为 ad-hoc 签名，未经 Apple 公证 |
| 快捷键写入 | 用户在 Codex 输入框确认中文替换为英文 | 不代表所有应用的可编辑控件均兼容 |
| 自动划词与浮窗 | 用户确认划词触发、深色文字清晰 | 多显示器、全屏及特殊控件仍需扩展验证 |
| 关闭浮窗 | 用户确认关闭后留在聊天；原生日志确认交还焦点成功 | 当前修复针对 macOS |
| 系统翻译段落 | 实际选区补回两个分隔，用户确认三段译文分别显示 | 不保证所有应用都暴露段落结构 |
| 语言包复用 | 中→英、英→中、重复翻译均使用已安装模型；规则检查通过 | 另一台 Mac 的缺包下载、macOS 15 兼容分支待复测 |
| 自定义 LLM | GLM-5.3 实际双向翻译、代码样例校验及工作台调用成功 | 其他服务和模型需使用自己的配置测试 |
| 局域网互传 | 两台实体 Mac 双向文字、多个文件往返，逐字节核对一致 | 约 256 KiB 合成文件样例，不代表大文件压力测试 |
| 后台接收 | 本机原生应用关闭主窗口后接收受信任测试实例的文件 | 与双机网络测试分开验证 |
| 本地存储 | SQLCipher、错误／缺失密钥、文件权限和重开回归；同一构建重启无钥匙串请求 | 未实际重装操作系统 |
| Windows 适配 | 原生取词、图标和文件权限模块经过交叉编译检查 | 尚未完成 Windows 整应用及实机验收 |

## 自动检查与复测

仓库保留 Rust 测试和 macOS 原生段落／模型规则检查。执行方法见开发指南；测试数量随代码变化，不在本文固定为某次构建的数字。CI 配置为 macOS / Windows 两个平台，但需在实际仓库运行并查看结果。

真实网络、在线模型和人工核码诊断默认不属于常规自动测试。模拟 IPC、交叉编译、工作台翻译分别证明对应层的行为，不能替代目标应用中的前台划词或两台实体电脑的网络实测。

## 仍需覆盖

- Windows 的 UI Automation、快捷键、回填、图标、文件 ACL、安装与后台资源占用。
- macOS 13/14、macOS 15 系统翻译下载分支、Intel Mac，以及多屏／不同缩放和全屏应用。
- 混合自然语言、未标记代码、注释和命令的选区；尤其是源应用丢失段落或代码边界的情况。
- 接近协议上限的大文件、长时间运行、断网、磁盘不足、休眠恢复及不同网络拓扑。

性能检查应同时统计主进程与 WebView 子进程。历史短测支持减少空闲正文读取和 CPU 唤醒，但不据此承诺固定内存占用或宣称整应用内存已显著降低。
